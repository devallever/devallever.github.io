📱1. About FakeCall

FakeCall is an Android app that simulates incoming phone calls on your device. You can customize the caller number, contact name, location label, ringtone, wallpaper, and more — then trigger a fake call manually or schedule it for later. It is intended for entertainment, demonstration, or as a practical excuse to leave a situation.

FakeCall runs 100% locally. No network connection is required. No cloud servers are involved.

✅2. What Data Do We Collect?

The short answer: absolutely nothing.

FakeCall does not declare the INTERNET permission in its AndroidManifest, which means your device never opens a network connection on our behalf. Everything you configure inside the app — fake phone number, contact name, ringtone choice, wallpaper selection, avatar path, repeat interval — is stored only on your device's local storage and never uploaded to any server.

🔐3. Permissions Explained

To deliver a realistic fake-call experience, FakeCall declares only three permissions — all are non-sensitive and never trigger a runtime pop-up dialog:

  • Vibrate Triggers the device vibrator during the simulated call to mimic a real incoming call.
  • Disable Keyguard Wakes the device and bypasses the lock screen so the incoming-call UI can be displayed.
  • Wake Lock Keeps the device awake while the fake call screen is active, preventing automatic screen-off.

The following permissions are NOT declared: Internet access, Contacts (full read), Phone dialing, Fine/Coarse location, Microphone, Camera, Storage read/write, Notifications, Overlay window, Request install packages, Exact alarm, Battery optimization exemption, and more.

🔗4. Third-Party SDKs & Data Sharing

FakeCall contains no third-party analytics, advertising, attribution, or crash-reporting SDKs. The only external libraries used are the official Google AndroidX components (Material Design, Lifecycle, Coil image loading, etc.), which are part of every modern Android app and do not send data off-device.

Accordingly, we do not share any user data with third parties, because there is nothing to share.

💾5. Local Storage & On-Device Privacy

Everything you configure inside FakeCall — caller number, contact label, location, ringtone, wallpaper, avatar path, repeat count and interval, etc. — is stored as simple key-value pairs using Android's SharedPreferences / MMKV engine, inside the app's private directory at /data/data/app.funnyappptech.android.fake.call/.

This directory is protected by the Android sandbox and is readable only by FakeCall itself. When you uninstall the app, the operating system automatically removes all stored data. Nothing is left behind.

About custom avatars and wallpapers:

When you pick a custom avatar or wallpaper using the system photo picker (ActivityResultContracts.PickVisualMedia), FakeCall copies the selected image into its private directory and stores the absolute file path. Your original photo in the system gallery is never modified or deleted.

📇6. About the Contact Picker

When you tap "Pick from Contacts", FakeCall sends an ACTION_PICK Intent to the system Contacts app. You make the selection in the native Android contact picker — not inside FakeCall.

Under Android's official guidelines, this is a "trusted Intent path" that does not require the READ_CONTACTS runtime permission. The system only returns the single contact entry you explicitly selected (name + phone number). FakeCall never reads your entire contacts book.

👶7. Children's Privacy

FakeCall is suitable for users of all ages. We do not knowingly collect any personal information from children under 13. The app contains no mature content and is appropriate for family use.

🗑️8. How to Delete Your Data

Since all data lives only on your device, deletion is straightforward:

1. Clear app data: System Settings → Apps → FakeCall → Storage → Clear Data (keeps the app installed)
2. Uninstall the app: Removing FakeCall will automatically delete all local data.

There are no cloud servers involved, so no additional data-deletion request is needed.
